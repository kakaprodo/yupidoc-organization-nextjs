# YupiDoc Organization

This application serves as the marketplace for an individual training center (organization) registered on YupiDoc.

## Goal

The goal of this application is to enable training centers to publish their courses and programs, making them accessible to students.

All content published through this application is read-only. It allows students to learn more about a training center, explore its courses and programs, and enroll in those they wish to attend on YupiDoc.

## Mock Data

During development, you can load sample data by running:

```bash
npm run dev-with-data
```

This command fetches content from a predefined test organization and saves it to:

```text
scripts/training-center-contents.json
```

The downloaded data is then used to populate the application with sample content for local development and testing.
